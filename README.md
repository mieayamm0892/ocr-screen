# ocr-screen

Simple OCR screenshot tool for Wayland/Hyprland.

## Features

- Select screen area with slurp
- Screenshot using grim
- OCR using Tesseract
- Copy text directly to clipboard

## Dependencies

Arch-based distributions (CachyOS, Arch Linux, EndeavourOS, etc.):

```bash
sudo pacman -S grim slurp tesseract wl-clipboard
